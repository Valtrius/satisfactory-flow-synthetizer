# Release highlights

- Exact synthesis now uses cvc5 end to end. The Windows x64 installer and portable ZIP bundle cvc5 and its license notices, so no separate solver setup is needed.
- One min N/L, All min N/L and All min N keep their requested scope through queued jobs and history. Enumeration, cancellation and capped searches retain exact completion semantics.
- History and desktop reliability were tightened with five-second checkpoints, transactional append saves, graph-state isolation, keyboard navigation and close/save recovery.

The same release benchmark set used for 0.2.0 was rerun on the same Windows machine with 16 workers on the `ffff` 96 MiB L3 CPU set. The four longer cases are 64–90% faster than 0.2.0. The shorter 24/65 cases regress in wall time, but all remain below 1.7 seconds.
