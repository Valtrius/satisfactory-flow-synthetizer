# Solver and application contracts

Code map: solver-core has normalization (problem.rs), sound arithmetic bounds (lower_bound.rs), exact profiles (profile.rs), QF_LRA encoding (encoding.rs), Boolean counts (cardinality.rs), portable objective/root planning (planner/), and the incremental leaf protocol (leaf.rs). The default native-runtime feature adds process.rs, native.rs, native_api.rs, diagnostics.rs and the independent portfolio.rs host. solver-api defines exact contracts; solver-validation independently checks graph equations, capacity, reachability, global/SCC uniqueness and layout-v1 identity. solver-reference is the exhaustive small-case oracle. synthetizer-app presents solutions; src-tauri owns jobs/IPC/history; frontend owns queue and graph UI.

Scale rates/capacity by one positive factor while preserving terminals. Search N, exact L and all accounted profiles. Unary multiplicities, sorted same-type flows, direct single-input equalities and decreasing selected reachability paths preserve cycles and every physical graph. Unexpected extraction/validation failures stop the worker; reject nonunique steady states.

For multiple workers, every first-output producer is an exhaustive disjoint root; dispatch producers descending. Boolean All min N/L groups with >=2 outputs and >1 branch worker select from unsplit live roots. Fewer roots than branch workers: static second-output children replace parents and all must exhaust. Otherwise: parents continue, and a validated current-group optimum witness permits adaptive children in spare slots after unstarted parents. Stable rounds interleave second producers. Either the parent OR a complete child cover owns an obligation, never both. Partial/duplicate completions cannot prove exhaustion. Preserve the exact promoted scheduler from the qualified hybrid source.

Sparse/Boolean searches split the total workers independently; sparse gets the odd extra, one worker is Boolean only. Each branch owns its ledger. Join both branches and backend sessions before terminal events, return one proof owner, never sum ledgers. One min N/L stops siblings after the first proved optimum without claiming enumeration exhaustion. User cancellation wins over racing internal success and remains incomplete. Desktop cancellation closes when search seals; hidden shutdown owns and joins job threads before exit. See docs/development.md for persistence and cleanup dialogs.

History schema 4 stores no solver type. JSON versions through 2 and relational schema 3 migrate transactionally with selections and graph edits. Unknown/corrupt schemas fail without deleting data. Strip imported engine prefixes from layout caches. Five-second checkpoints preserve interrupted work as incomplete; terminal snapshots release after frontend acceptance. Detached acknowledged snapshots permit suffix appends only for unchanged prefixes. Corrections use full replacement; prefix mismatches recover atomically without rewriting unrelated entries. Keep history-fixtures/v2.sql and cross-language wire fixtures.

The collector establishes public layout keys after rate/terminal restoration; presentation reuses those keys, not private search keys. Terminal conversion reuses matching live best-known displays without proofs and reconstructs missing or finalized cache entries. Proof application and cancellation remain independent of display caching.

Portable host contract: execute LeafAction batches in one persistent session, publish an accepted witness before the next blocking call, and dispose the backend before PlannerEvent::Retired. An ExactPlanner owns one branch only. poll seals completion only after every dispatched leaf retires; cancellation accepted before that poll wins. Reject foreign job epochs in the host and stale group/leaf IDs in the planner. Raw branch events need the same caller-scale identity normalization as native SolutionCollector before app delivery. outcome normalizes and orders public identities. No unsafe Send/Sync bridges or private-heap atomics for cross-worker cancellation. Canonaut's vendored word-width patch and pre-port identity evidence are described in docs/web-backends.md and vendor/canonaut/PORTABILITY.md.

Browser host: solver-browser owns exact request preparation, one Boolean planner/leaf and shared Rust presentation. solve.worker.ts owns cvc5 sessions; browserJobs.ts owns worker termination, attempts, admission and the completion seal. Before another blocking call, publish accepted graphs plus thin Rust interruption_packet projections and await the page ACK. The page retains full graphs and applies cancellation/failure metadata only after worker termination. Completion disposes sessions/frees the Rust run, then the page terminates the worker and seals before delivering the full terminal snapshot. Cancellation before that host seal wins; after it cannot rewrite completion. Stale attempts, sequence gaps and malformed packets never add proof. A disposal exception requires whole-worker retirement, not a false leaf retirement. Startup has a 120-second limit; there is no solve deadline after backend readiness. Keep all three scopes, full-get reconciliation and live source indices. Browser history saves interrupted checkpoints without resumption. Lazy content-hashed solver assets are separate from the small verifier and omitted in desktop Vite mode. Tests: web/solver, frontend browserJobs tests, Rust shared interruption tests, scripts/test_web_solver.py. Parallel compute, paged collections and offline assets remain later phases.
