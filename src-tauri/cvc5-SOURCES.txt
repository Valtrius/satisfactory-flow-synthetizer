This distribution includes the unmodified official cvc5 1.3.4 Windows x64
static executable, used as a separate process. Its release archive, binary
checksum and source location are recorded in package.json beside this file.

cvc5 source, build scripts and dependency configuration:
https://github.com/cvc5/cvc5/tree/cvc5-1.3.4
https://github.com/cvc5/cvc5/archive/refs/tags/cvc5-1.3.4.tar.gz

The official cvc5 release archive also provides headers, static libraries and
CMake package files. Refer to the source tree's README and cmake/Find*.cmake
files for build instructions and exact dependency download checksums.

COPYING and AUTHORS are reproduced from the cvc5 release archive. The licenses
directory contains its bundled notices plus the matching CaDiCaL, LibPoly and
SymFPU notices. cvc5 and its dependencies retain their respective licenses;
the application's license does not replace them.
